Core Architecture

How the Automation System Works

Step-by-step pipeline from test invocation to final HTML report generation

STEP 01
Launcher
run_tests.bat or BehaveTestRunner.py resolves Python environment and CLI mode.
→
STEP 02
Singleton Browser
environment.py initializes one shared Chrome instance with download preferences and waits.
→
STEP 03
Auto-Login
Executes login.feature first to authenticate, expand menus, and reach the dashboard.
→
STEP 04
Feature Scenarios
Executes target feature (Forms, Tickets, Users). Reuses active session without re-logging in.
→
STEP 05
Diagnostic Report
On failure, captures screenshot to screenshots/; compiles JSON into interactive HTML report.
⚡
Shared Browser Session

Instead of reopening Chrome for every single scenario, environment.py holds a global driver singleton. This cuts total execution time by up to 70% and eliminates flaky re-authentications.

📸
Automated Failure Capture

The after_scenario hook automatically captures a timestamped full-page PNG screenshot on any assertion failure and records it in screenshot_index.json for report embedding.

📊
Custom Reporting Engine

generate_report.py parses Behave's raw JSON telemetry into standalone, color-coded HTML test dashboards that can be viewed offline or attached to test records.

Configuration

Centralized settings file containing LOGIN_URL, USERNAME, PASSWORD, TENANT_CODE, WAIT_TIMEOUT, and CLOSE_BROWSER_AFTER_TEST. No credentials need to be hardcoded in Python code.

Execution Guide

How to Run Automation Tests

Multiple ways to run: One-click Batch launcher, Python CLI, and Behave native

The easiest way for QA team members and stakeholders. Simply double click run_tests.bat from Windows Explorer:

REM In Windows Explorer:
Double-click run_tests.bat

Displays Interactive Menu:
[1] Run ALL feature files
[2] Run tests by TAG (e.g., @smoke)
[3] Browse and select a specific feature file
[4] Exit
What happens under the hood?
  • ✓ Automatically detects Python installation on PATH or user directory
  • ✓ Verifies ChromeDriver and required dependencies
  • ✓ Prompts to open the generated HTML report immediately when done

BehaveTestRunner.py offers flexible command-line arguments for CI/CD or power users:

# 1. Interactive terminal menu
python BehaveTestRunner.py

# 2. Run all features sequentially
python BehaveTestRunner.py --run-all

# 3. Run a specific feature file
python BehaveTestRunner.py --feature features/Forms/Demo.feature

# 4. Filter execution by Gherkin tag
python BehaveTestRunner.py --tag @smoke
Key Features of the Runner

• Automatically injects login.feature before the selected feature.
• Pipes structured JSON into generate_report.py.
• Returns exit code 0 on pass and 1 on failure for CI/CD builds.

You can also run directly with Behave CLI for custom flags and step debugging:

# Dry-run validation (checks step definitions without opening Chrome):
python -m behave --dry-run

# Run login + specific feature with live console output:
python -m behave --no-capture features/login.feature features/Forms/Demo.feature

To prepare a brand new PC for testing, run setup.bat:

setup.bat
What setup.bat checks:
1. Internet connection & Google Chrome existence
2. Python 3.10–3.15 installation (downloads if missing)
3. Upgrades pip & installs selenium, behave, webdriver-manager, python-dotenv
4. Ensures required folders (reports, screenshots, downloads) exist

Summary & QA Team Workflow

Standard operating procedure for creating, testing, and maintaining automated tests

Standard 3-Step QA Workflow
1
Write Feature in Gherkin:
Create or update a .feature file inside features/Forms/ using steps from ARTIFACTS_GUIDE.html.
2
Validate Steps (Dry-Run):
Run python -m behave --dry-run to ensure all steps match definitions in all_steps.py.
3
Execute & Review Report:
Run via run_tests.bat, review the auto-opened HTML report, and inspect any failure screenshots.
Quick Command Cheat Sheet
# Run complete regression suite:
python BehaveTestRunner.py --run-all

# Run specific smoke tests:
python BehaveTestRunner.py --tag @smoke

# Verify all steps without browser:
python -m behave --dry-run

# Guidance file with searchable steps:
start ARTIFACTS_GUIDE.html
