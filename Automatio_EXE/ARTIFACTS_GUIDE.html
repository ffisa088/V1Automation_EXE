Overview & Architecture System

BDD
Behavior-Driven Development
Test scenarios are written in Gherkin feature files (features/Forms/*.feature). Behave binds each English sentence to Selenium code.
SESSION
Singleton Browser Session
Chrome is launched once by features/environment.py and kept open across all scenarios, avoiding repeated logins and cutting execution time by 70%.

Directory Structure Layout

AUTH
features/steps/auth/login_steps.py
Handles login, tenant code entry, company selection, credentials, and dashboard arrival.
STEPS
features/steps/common/all_steps.py
180+ universal step definitions covering navigation, buttons, inputs, dropdowns, DevX tables, calendars, modals, and downloads.
HELPERS
features/steps/common/helpers.py
Core Selenium utilities: fast element resolution, automation ID selectors (aid()), scroll helpers, and value resolution.

Authentication & Login Steps login_steps.py

GIVEN
Given I open the login page
Navigates to LOGIN_URL configured in config.env.
WHEN
When I enter the tenantCode
Inputs tenant code from config into inp_tenantcode.
WHEN
When I select the company "{company_name}"
Searches and clicks the specified company name in tenant selection.
THEN
Then I click on the Continue button
Clicks the tenant code continue button (btn_continue).
WHEN
When I enter the username
Types the username from config.env into inp_username.
WHEN
When I enter the password
Types the password from config.env into inp_password.
THEN
Then I click on the Sign In button
Clicks the sign in / submit button (btn_signin).
THEN
Then I should see the dashboard page
Verifies dashboard toolbar/navigation has successfully loaded.
THEN
Then I expand all menus in the toolbar
Expands all sidebar toolbar menus to make all feature items clickable.

Navigation, Menus & Tabs all_steps.py

GIVEN
Given I am on the "{page_name}" page
Asserts or waits until the specified page header is visible.
GIVEN
Given I am on the dashboard page
Verifies the user is on the main application dashboard.
WHENTHEN
When I click on "{menu_item}" from the menu
Finds and clicks a menu navigation link (e.g., "User Management", "Ticket Manager").
GIVEN
Given I am on the "{tab_name}" menu tab
Verifies that the specified upper menu tab is active.
WHENTHEN
When I switch to the "{tab_name}" menu tab
Clicks the tab header to switch active workspace view.
WHENTHEN
Then I switch to tab "{tab_name}"
Alias for tab switching (e.g., "My Request", "Common Task").
THEN
Then I should see the "{tab_name}" menu tab is active
Asserts that the tab has active/selected CSS class.
WHENTHEN
Then I close the "{tab_name}" menu tab
Clicks the close 'x' icon on the designated workspace tab.
THEN
Then the "{tab_name}" menu tab should not exist
Verifies that the tab is removed from the DOM.

Dynamic Variables & Resolvers helpers.py

VAR
{timestamp}
Resolves to current date & time: 2026-09-21 11:30:00. Ideal for unique usernames.
VAR
{date}
Resolves to current date in ISO format: 2026-09-21.
VAR
today+3 / today-1
Dynamic relative dates. Automatically calculates future or past calendar dates.
VAR
{unix}
Current unix timestamp in seconds for guaranteed uniqueness.
